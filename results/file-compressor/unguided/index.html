Compiled WebAssembly Engine Features

LZ4

LZ4 Frame Engine

Compiled from official open-source LZ4 C library. Delivers compression and decompression speeds exceeding 500 MB/s directly within the WebAssembly virtual machine.

GZIP / ZLIB

Zlib Deflate Engine

Compiled from official open-source Zlib C source code. Fully standards-compliant RFC 1952 (GZIP) and RFC 1950 (ZLIB) with variable compression levels 1 to 9.

RLE

Run-Length Encoder

Custom PackBits-style run-length compression written in C++ with 64-bit size verification headers and safe bounds checking.
